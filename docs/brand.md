# BOECL brand

`BOECL` is the canonical public product and publication name. Use the uppercase spelling
consistently in navigation, administration screens, page metadata, social metadata, and
future visual assets.

The existing `peletnapechkai.com` domain and internal technical identifiers remain in
place until a separately planned infrastructure migration. Names such as .NET projects,
Windows services, database roles, deployment directories, and Git repository paths are
implementation details and must not be presented as the publication name.

Brand translations must not alter the `BOECL` proper name. Supporting descriptions and
interface copy remain localized for every supported locale.
